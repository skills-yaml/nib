# Tech Doc Template

Use this template for required and conditional files under
`workspace/instructions/tech/`.

```md
# [Topic]

Metadata:

- Standard: workspace-docs@5.0.0
- Status: static
- Owner: project
- Last reviewed: YYYY-MM-DD

## Scope

State when this document applies and what it does not cover.

## Source of Truth

Name the files, commands, services, or specs that define current behavior.

## Required Rules

List rules that agents and contributors must follow.

## Workflow

Describe the repeatable process for this topic.

## Validation

List commands or checks that prove changes are correct.

## References

Link to related project docs and specs.
```

Tech docs are static by default. Automation must not rewrite project-owned tech
docs unless explicitly requested.
